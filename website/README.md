# JobOps marketing site

Static, responsive, accessible site. Open `website/index.html` or serve `website/` with a simple HTTP server. Pages: Home, Features, Docs, About, Contact, Search. Search is entirely client-side and theme preference is local. Canonical documentation lives in the repository. No contact form credentials are collected. No live submission claims.

For deployment, set website/ as Cloudflare Pages output directory or use GitHub Pages. Keep deploy approval separate from feature PR.
